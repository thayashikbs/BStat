3.1 平均値の差の検定

t検定は, Rで標準的に用意されている関数t.test()を用いて行う.

# t.test(x, y = NULL,
#    alternative = c("two.sided", "less", "greater"),
#    mu = 0, paired = FALSE, var.equal = FALSE,
#    conf.level = 0.95, ...)
#
#
#   One Sample t-test
# Performs one and two sample t-tests on vectors of data.

平均値の差の検定 (ペア検定)

ペア検定を実施する場合には, t.test()の引数pairedを真 (TRUE, またはT) に設定する. デフォルトは,paired = FALSE (F) である (ペア検定ではない).

データセット: call_handling_time.csv

両側検定, 片側検定は, 引数alternativeの値 (“two.sided”, “less”, “greater”) で指定する. デフォルトはalternative="two.sided", すなわち, 両側検定である.

同じオペレーター10名について, 旧マニュアル(method == 1)と新マニュアル(method == 2) での所要時間を対応づけて比較するため, paired = TRUEを指定する.

# 両側検定
t.test(time[method == 1], time[method == 2], paired = TRUE)
#> 
#>  Paired t-test
#> 
#> data:  time[method == 1] and time[method == 2]
#> t = 4.6374, df = 9, p-value = 0.001224
#> alternative hypothesis: true mean difference is not equal to 0
#> 95 percent confidence interval:
#>  0.6453664 1.8746336
#> sample estimates:
#> mean difference 
#>            1.26

旧マニュアルの方が時間がかかる (新マニュアルの方が短い) ことが狙いどおりであれば, 対立仮説として「旧 > 新」(すなわち, 差旧-新が正) を想定するのが自然である. 片側検定は, 右側はalternative = "greater", 左側はalternative = "less"で指定する.

# 片側検定

標本平均の差 (method==1の平均 − method==2の平均) は\(1.26\)分であり, 両側検定のp値は \(0.0012\)と, 1%有意水準 (\(\alpha=0.01\)) でも帰無仮説 (差はゼロ) は棄却される. また, 対立仮説を「旧 > 新」 とした片側検定でも, p値は\(0.0006\)とさらに小さく, 新マニュアルの方が後処理時間を有意に短縮していると判断できる. 一方, 逆向きの片側検定 (対立仮説「旧 < 新」) では, p値は\(0.9994\)と1に近く, こちらの仮説は全く支持されない. この非対称な結果は, 標本から観測された差の符号 (旧の方が長い) と整合的である.

平均値の差に関するt検定は, 二つの標本 \((x_1,x_2,...,x_{n_1})\), \((y_1,y_2,...,y_{n_2})\) の差\(\mu_1-\mu_2\)がゼロか否かを評価する統計的な手続きである (ここで, 未知の真の平均はそれぞれ, \(\mu_1\), \(\mu_2\)と表記する).

ペア検定は, さらに, この2標本のサイズが等しく (\(n_1=n_2\equiv n\)), しかも, 各々のデータ点がペア \((x_i,y_i)\) として扱える (“対応がある”) ような特別な場合である. 対応のあるケースの例としては, 同一のオペレーターについて, 新旧2種類の条件下でデータを採取した今回のようなケースである.

このようなペアのケースにおける平均値の差の検定は, 2標本のまま扱うのではなく, 各データ点ペアの差 \((x_i-y_i)\) を取ることで1標本に集約した上で, 1標本に対する平均値ゼロのt検定として行う.

すなわち, 帰無仮説\(H_0: \mu_1-\mu_2=0\)に対して, 対立仮説は,

  • 両側検定: \(H_1: \mu_1-\mu_2 \neq 0\)
  • 片側 (右側) 検定: \(H_1: \mu_1-\mu_2>0\)
  • 片側 (左側) 検定: \(H_1: \mu_1-\mu_2<0\)

である.

平均値の差の検定

ペアを構成しない一般の2標本の平均値の差に関するt検定においては, 2標本の持つ未知の分散の大きさが等しいかが問題になる.

t.test()のデフォルトでは等分散性が成立しない (var.equal = FALSE) 設定となっている. この時は, Welch検定が実行される.

もちろん, 等分散性が成立する場合には, var.equalの値はTまたはTRUE と指定せねばならない. この時は, 未知の分散はプール化された (“pooled”) 推定値を持ちいたt検定が行われる.

A/Bテストデータ (仮想データ)

デザイン A と B のどちらが平均的な購入意向を高めるか
- id, group (A:旧デザイン, B:新デザイン), purchase_intent (1--7)
- 標本サイズ: nA=50, nB=60
abtest_df <- read.csv("class/purchase_1-7.csv", header = T)
boxplot(purchase_intent ~ group, data = abtest_df)

等分散性の検定は, var.test()を用いることができる

# 等分散性の検定 (F検定)
var.test(purchase_intent ~ group, data = abtest_df)
#> 
#>  F test to compare two variances
#> 
#> data:  purchase_intent by group
#> F = 1.1253, num df = 49, denom df = 59, p-value = 0.6606
#> alternative hypothesis: true ratio of variances is not equal to 1
#> 95 percent confidence interval:
#>  0.6592874 1.9472951
#> sample estimates:
#> ratio of variances 
#>           1.125316
# ※ 省略されることも多い

その上で, Welch検定か, プール化された分散推定値を用いるt検定を実行する.

上の等分散性検定の結果より, 帰無仮説 (2標本の分散は等しい, \(\sigma_1^2=\sigma_2^2\)) は棄却されないことから (p値\(=0.6606\)), 等分散の場合について実行すれば良い.

# 等分散の場合 (Pooled variance使用するt検定)
t.test(purchase_intent ~ group, var.equal = T, data = abtest_df)
#> 
#>  Two Sample t-test
#> 
#> data:  purchase_intent by group
#> t = -4.3526, df = 108, p-value = 3.067e-05
#> alternative hypothesis: true difference in means between group A and group B is not equal to 0
#> 95 percent confidence interval:
#>  -1.1449141 -0.4284192
#> sample estimates:
#> mean in group A mean in group B 
#>        4.480000        5.266667

しかし, 繰り返し仮説検定を行うことによる弊害 (多重検定問題) を回避するため, 等分散性の検定を行わず, いきなりWelch検定を実行することも多い.

# 等分散でない場合 (Welch t検定)
t.test(purchase_intent ~ group, data = abtest_df)
#> 
#>  Welch Two Sample t-test
#> 
#> data:  purchase_intent by group
#> t = -4.3291, df = 101.99, p-value = 3.505e-05
#> alternative hypothesis: true difference in means between group A and group B is not equal to 0
#> 95 percent confidence interval:
#>  -1.1470981 -0.4262352
#> sample estimates:
#> mean in group A mean in group B 
#>        4.480000        5.266667

いずれの方法でも, p値は\(3\times10^{-5}\)程度と非常に小さく, 新デザイン(B)の方が 平均購入意向 (A: \(4.48\) 点, B: \(5.27\) 点, いずれも7点満点) を有意に高めていることがわかる.

正規性の確認方法

t検定は, 標本を抽出するもととなる母集団の確率分布が 正規分布であるというのが分布に関する基本的な仮定である.

したがって, t検定の実行に先立ち, 標本が正規分布に従うか否かを調べ, t検定の前提条件が満たされているかどうかを確認することが求められる.

これは, 標本数が小さい時には特に注意する必要がある.

# ヒストグラム作成
A <- abtest_df[abtest_df$group == "A", "purchase_intent"]
B <- abtest_df[abtest_df$group == "B", "purchase_intent"]
hist(A, col = rgb(1, 0.5, 0, 0.5))
hist(B, col = rgb(0, 0.5, 1, 0.5), add = T)


# 正規性の検定
ks.test(A, "pnorm")
#> 
#>  Asymptotic one-sample Kolmogorov-Smirnov test
#> 
#> data:  A
#> D = 0.99865, p-value < 2.2e-16
#> alternative hypothesis: two-sided
ks.test(B, "pnorm")  # コルモゴロフ・スミルノフ (Kolmogorov-Smirnov) 検定
#> 
#>  Asymptotic one-sample Kolmogorov-Smirnov test
#> 
#> data:  B
#> D = 0.99865, p-value < 2.2e-16
#> alternative hypothesis: two-sided
shapiro.test(A)
#> 
#>  Shapiro-Wilk normality test
#> 
#> data:  A
#> W = 0.89953, p-value = 0.0004638
shapiro.test(B)  # シャピロ・ウィルク (Shapiro-Wilk) 検定
#> 
#>  Shapiro-Wilk normality test
#> 
#> data:  B
#> W = 0.89262, p-value = 7.16e-05
qqnorm(A)

qqnorm(B)  # q-qプロット

平均値の差の検定 (ノンパラメトリック検定)

上記のように, t検定は標本を抽出するもととなる母集団の確率分布が 正規分布であるというのが分布に関する基本的な仮定である.

しかしその一方で, 標本数が十分に大きい時は, 母集団の確率分布が 正規分布である必要はない.

それは, 中心極限定理の働きによって, 検定統計量が帰無仮説の下では 近似的にStudent t分布に従うことが理論的に示されるためである.

一方, 標本数が大きくない場合には, 母集団の確率分布が正規分布でない場合には, t検定の前提条件から乖離する状況となるため, 別の検定法を用いることが適切である.

ノンパラメトリック検定法は, 分布形状に関する仮定によらない, ロバスト (頑強) な検定方法である.

Wilcoxonの順位和検定 (Mann–WhitneyのU検定)

ここでは, 2群の平均値の差に関する t検定の代替的手法として, ウィルコクソン (Wilcoxon) の順位和検定を紹介する.

  • 2群の中央値の差を調べる
  • 外れ値に対して頑強
wilcox.test(purchase_intent ~ group, data = abtest_df)
#> 
#>  Wilcoxon rank sum test with continuity correction
#> 
#> data:  purchase_intent by group
#> W = 861.5, p-value = 5.992e-05
#> alternative hypothesis: true location shift is not equal to 0

# A,Bを定義しておいた場合, 以下の実行も可能 wilcox.test(A, B)

3.2 カイ二乗検定

前節で扱った平均値の差の検定は, 連続的な数量データを対象とするものであった. これに対して, カイ二乗 (\(\chi^2\)) 検定は, カテゴリー (質的) データに対する 代表的な検定手法であり, 実務では以下のような場面でよく用いられる.

  • 独立性の検定: 2つのカテゴリー変数の間に関連があるか (独立かどうか) を調べる
  • 適合度検定: 観測された度数の分布が, あらかじめ想定した理論分布と一致しているか調べる

いずれも, Rのchisq.test()関数を用いて行う.

# chisq.test(x, y = NULL, correct = TRUE,
#   p = rep(1/length(x), length(x)), rescale.p = FALSE,
#   simulate.p.value = FALSE, B = 2000)
# chisq.test performs chi-squared contingency table tests and goodness-of-fit tests.

独立性検定

2つのカテゴリー変数が独立かどうかを調べるには, 分割表 (クロス集計表) を作成し, chisq.test()に渡す.

\(\chi^2\)統計量は\(27.66\) (\(df=6\)), p値は\(0.0001\)程度と非常に小さく, 商品種類と販売チャネルの間には (帰無仮説「独立である」を棄却するに十分な) 関連が あると判断できる.

A/Bテストへの応用 (サイト導線とコンバージョン)

独立性検定は, A/Bテストにおいて, 「施策群 (A/B)」と「結果 (成功/失敗)」という 2つの2値カテゴリー変数の関連を調べる場面でも利用できる.

# サイト導線A/Bとで, コンバージョンへの効果を比較 \t\t\t\t\t\t有\t\t\t\t無
# \tサイト導線A\t50\t\t\t\t131 \tサイト導線B\t23\t\t\t\t35
ABdat <- matrix(c(50, 131, 23, 35), ncol = 2, byrow = T)
chisq.test(ABdat)
#> 
#>  Pearson's Chi-squared test with Yates' continuity correction
#> 
#> data:  ABdat
#> X-squared = 2.4566, df = 1, p-value = 0.117

# 導線Aでコンバージョンしない人が10人増えた \t\t\t\t\t\t有\t\t\t無
# \tサイト導線A\t50\t\t\t141 \tサイト導線B\t23\t\t\t 35
ABdat2 <- matrix(c(50, 141, 23, 35), ncol = 2, byrow = T)
chisq.test(ABdat2)
#> 
#>  Pearson's Chi-squared test with Yates' continuity correction
#> 
#> data:  ABdat2
#> X-squared = 3.2764, df = 1, p-value = 0.07028

# Fisherの正確確率検定
fisher.test(ABdat2)
#> 
#>  Fisher's Exact Test for Count Data
#> 
#> data:  ABdat2
#> p-value = 0.06915
#> alternative hypothesis: true odds ratio is not equal to 1
#> 95 percent confidence interval:
#>  0.2796541 1.0568106
#> sample estimates:
#> odds ratio 
#>  0.5410443

ABdatでは, p値\(=0.117\)と, 5%水準では導線A/Bとコンバージョンの関連 (独立性からの 乖離) は認められない. ABdat2のように, 導線Aで「コンバージョンしない」人数が 10人増えると (全体のサンプルサイズが変わる), p値は\(0.070\)とやや小さくなるが, それでも5%水準では有意ではない. なお, chisq.test()は2×2分割表では デフォルトでYatesの連続性補正を行うため, 標本サイズが小さい場合には, 補正を行わないFisherの正確確率検定(fisher.test())を用いる方が適切な場合もある (ここでは両者ともp値\(\approx0.07\)と近い結果になっている).

適合度検定

適合度検定は, 観測された1つのカテゴリー変数の度数分布が, あらかじめ想定した 理論的な分布 (確率) と一致しているかを調べる.

# メンデルのデータ（エンドウの交雑実験） 種子の特徴(形質), 黄色・丸い,
# 黄色・しわ, 緑色・丸い, 緑色・しわ
obs <- c(315, 101, 108, 32)  # 観測度数
prob <- c(9, 3, 3, 1)/16  # 理論確率分布
chisq.test(obs, p = prob)  # obs と prob を用いたカイ二乗検定
#> 
#>  Chi-squared test for given probabilities
#> 
#> data:  obs
#> X-squared = 0.47002, df = 3, p-value = 0.9254

# 確認用 (chisq.test()の計算過程を手計算で再現)
ex <- prob * sum(obs)
chisq <- sum((obs - ex)^2/ex)
pval <- 1 - pchisq(chisq, 3)

メンデルの交雑実験の例は, 遺伝の法則 (9:3:3:1の理論比) が観測データに よく当てはまる (p値\(=0.925\)と非常に大きく, 帰無仮説は全く棄却されない) 古典的な適合度検定の教材である.

ビジネスデータへの応用例 (新商品のカラー展開)

ビジネスの文脈では, 「市場調査などで事前に想定していた比率 (シェア) と, 実際の販売実績が一致しているか」を確認する場面で, 適合度検定が使われる.

# 新商品(スマホケース)のカラー展開: 発売前の市場調査に基づく想定シェアと,
# 発売1か月間の実売数 (合計400個) が一致していると言えるか 色: 黒, 白, 青, 赤
obs_color <- c(140, 110, 90, 60)  # 観測度数 (実売数)
names(obs_color) <- c("黒", "白", "青", "赤")
prob_color <- c(0.4, 0.3, 0.2, 0.1)  # 想定シェア (市場調査による事前予測)
chisq.test(obs_color, p = prob_color)
#> 
#>  Chi-squared test for given probabilities
#> 
#> data:  obs_color
#> X-squared = 14.583, df = 3, p-value = 0.00221

# 確認用
ex_color <- prob_color * sum(obs_color)
chisq_color <- sum((obs_color - ex_color)^2/ex_color)
pval_color <- 1 - pchisq(chisq_color, 3)

こちらは, \(\chi^2=14.58\) (\(df=3\)), p値\(=0.0022\)と, 5%水準 (1%水準でも) で 帰無仮説「実績は想定シェアと一致する」が棄却される. 実際には黒・赤が想定より 多く売れ, 白・青が想定より少ない結果になっている. メンデルの例とは対照的に, 「事前の想定 (理論分布) と実績データが一致していない」ことを示す例であり, 販売計画・生産計画の見直しが必要になる場面に対応する.

#> Warning in chisq.test(table(total_score, it_years_grp)): Chi-squared

#>

#> 
#> data:  table(total_score, it_years_grp)
#> X-squared = 35.107, df = 28, p-value = 0.1668

このコードは実行はできるが, 結果の解釈には注意が必要である. total_scoreは 本来連続的な (14〜29点の) 数量データであり, これをit_years_grp(3分類)との 分割表にすると, 行数 (total_scoreの取り得る値の種類数, ここでは15) に対して 標本数 (45) が少なすぎるため, ほとんどのセルの観測度数が0か1になってしまう (非常にスパースな分割表になる). この結果, 「カイ二乗近似は不正確かもしれません」 という警告が出る上に, 検定自体がほとんど情報を持たない. カイ二乗検定は, カテゴリー変数同士の関連を調べる手法であり, 連続量をそのまま分割表にするのは 誤用である点に注意したい. 連続量と群 (カテゴリー) の関係を調べたいのであれば, 上記の分散分析のように, 連続量を応答変数として扱う方が適切である.
