9 決定木分析

決定木 (decision tree) は, 学習データに含まれる説明変数空間を, 目的変数との関係に基づいて (目的変数がなるべく均質になるように) 階層的に分割する手法である.

この分割は, 目的関数（回帰問題であればMSEなど, 分類問題であればジニ不純度やエントロピー等）を最適化するように, 一回につき1変数, 学習データに基づいて逐次行われる.

逐次分割のルールは, 木構造で表現される.

  • ルートノード： 木の最上部. データセット全体を表現
  • (内部) ノード： データセットの分割条件 (質問や条件)を表現. データセットが分割される
  • リーフノード （末端ノード）: 分類されたデータセットの最終的な出力を表現. これ以上の分割は行われない

「決定木はデータセットの分割ルールを自動生成する」 という説明がなされることがあるが, 不正確であることに注意が必要である.

正確には, 生成されるのは「説明変数空間の分割規則」であり, 分割後の各領域に対応した予測値（分類ラベルや回帰適合値） が付与されているに過ぎない.

決定木分析を行う標準的な関数として, パッケージrpartの関数rpart()がある. 回帰木, 分類木どちらにも適用可能である. 本章の内容は, 授業の R 演習スクリプト R_DT_dist.R に対応する.

  • 【分割1】speedが17.5未満か/以上か
  • 【分割2】(speedが17.5未満の領域に対して) speedが12.5未満か/以上か

printcp()の出力のCPは複雑度パラメータ cp, nsplitは分割の回数 (末端ノード数 - 1), rel errorは学習データに対する誤差, xerrorは交差検証 (CV) による予測誤差, xstdはその標準誤差である (誤差はいずれも, 根ノード (分割なし) の誤差を1とした相対値).

plotcp()は, 複雑度パラメータ cp (下側の横軸. 上側の横軸は対応する木のサイズ = 末端ノード数) に対する 交差検証 (CV) 予測誤差 (縦軸) をプロットした図である. 図の右に行くほど cp は小さく, 木は大きく (複雑に) なる. 点線は, CV 誤差の最小値にその標準誤差を1つ加えた水準であり, 点線を下回る中で最も左の (最も単純な) 木を選ぶのが, 通常推奨される選び方 (1-SE ルール) である. 最も単純な木を選ぶのは, CV 誤差の差が標準誤差の範囲内であれば, 誤差の違いは偶然によるものとみなせるからである.

今回の図では, 木を大きくする (cp を小さくする) につれて CV 誤差はおおむね減少しており, 最小の CV 誤差は最も大きい木 (末端ノード数 7) で得られている. 1-SE ルールでは, 点線 (0.772) を下回る最も単純な木として, 末端ノード数 5 の木 (cp = 0.0118) が選ばれる.

なお, CP表の xerror は, 交差検証のデータ分割に乱数を使うため, 実行するたびに少し変わる. 結果を再現できるようにするには, rpart() を実行する前に set.seed() で乱数のシードを固定しておくと良い (ここでは, データ分割の前にset.seed(100)を実行しているので, 結果は再現される).

手動による剪定例

関数prune()を使うことで, アルゴリズムによる自動的な木構造の決定のあと, 事後的に枝を切ることで木の大きさを小さく整える (剪定する) ことができる. 剪定には, 上述の cp の大きさを指定する. ここでは, 例示のため, cp を大きめに取ってみる (→ 結果的にリーフの数が3枚になる).

# 手動による剪定例 (complex parameter(cp)の大きさに基づいて)
wine_rp1 <- prune(wine_rp, cp = 0.03)
plot(wine_rp1, uniform = T, margin = 0.05)
text(wine_rp1, all = T, use.n = T)

1-SE ルールで選んだ木に剪定する場合は, 次のようにすれば良い.

wine_rp_1se <- prune(wine_rp, cp = cpt[k_1se, "CP"])
rpart.plot(wine_rp_1se, digit = 3)

回帰木の場合と同様に読む. このデータでは, 木を大きくするにつれて CV 誤差が大きく減少しており, 1-SE ルールでも, 末端ノード数 15 の比較的大きな木が選ばれる. 評価は, いくつかの条件の組合せで決まる (例えば安全性が低ければ, 他の条件によらず「受け入れられない (unacc)」) ため, 分割を重ねることで分類の精度が上がるのだと考えられる.

木が大きく, 全体を読み取るのは難しい. 引数control = rpart.control(cp = 0.1)のように cp を大きく指定して適合すると, 小さな木が得られ, 主要な分割ルールを読み取りやすくなる.

res_rp_small <- rpart(評価 ~ ., data = car_train, control = rpart.control(cp = 0.1))
rpart.plot(res_rp_small, digit = 3)

最初の分割は安全性 (安全性 = low なら unacc), 次は乗車人数 (乗車人数 = 2 なら unacc) であり, この2つの条件だけで, 多くの車が「受け入れられない」と判定されることが分かる.

パフォーマンス評価

学習済モデルを使い, テスト用データで外挿予測を行う.

car_rp_pred <- predict(res_rp, car_test, type = "class")  # クラス分類の予測結果出力
# car_rp_pred <- predict(res_rp, car_test, type = 'prob')\t# 確率の出力

ここでは, パッケージcaretの関数confusionMatrix()を使い, 混同行列に基づいて各種パフォーマンス評価指標を計算する (評価指標の定義は「分類モデルの評価」で扱う). confusionMatrix()では, 2種類の表示モードを選択することができる:

  • 適合率 (precision) - 再現率 (recall) 表示
  • 感度(sensitivity) - 特異度 (specificity) 表示

今回のように3クラス以上の分類では, 各クラスについて「そのクラスか, それ以外か」の2クラスとみなした指標が, クラスごとに (Class: unacc などの列として) 出力される.
